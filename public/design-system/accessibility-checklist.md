# POZAN accessibility checklist

## Structure
- Use one meaningful page heading and a logical heading hierarchy.
- Use landmarks and semantic controls before adding ARIA.
- Keep content order meaningful without CSS layout.

## Keyboard and focus
- Every interactive element is reachable and operable with keyboard.
- Focus is visible, ordered and restored after dialogs close.
- Escape closes dismissible overlays.

## Content and media
- Meaningful images have useful alternative text.
- Decorative imagery uses empty alt text or is hidden from assistive technology.
- Video does not autoplay with sound and motion can be reduced.

## Visual
- Text and controls maintain sufficient contrast.
- Information is not communicated by color alone.
- Touch targets are at least 44 by 44 CSS pixels where possible.

## Responsive
- Content works at 200% zoom.
- No essential content is lost at 320 CSS pixels wide.
- Hover-only information has a touch and keyboard equivalent.
